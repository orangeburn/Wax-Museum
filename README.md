# 蜡像馆

![蜡像馆背景图](background.png)

《蜡像馆》是一套面向中文互动悬疑体验的叙事游戏引擎原型：玩家用自然语言直接行动，系统把角色属性、掷骰检定、场景物件、NPC 回合与故事线索编织成一局可持续推进的悬疑现场。当前项目已经支持模板化危机场景、LLM 辅助生成故事骨架、基于行动点与先攻排序的回合流程、本地存档，以及让玩家与 NPC 在同一信息边界下推进局势的规则内核。

## 当前能力（现状）

- 模板局可直接开玩：默认模板可即开即玩，适合作为基础体验入口。
- 自定义故事可用：输入一句 Prompt，即可生成故事背景、角色、地点与主线节点。
- 角色随题材动态生成：不再固定为预设职业模板，角色设定会跟随故事题材变化。
- 角色秘密目标可追踪：每个可选角色都会获得私密任务，并在游玩中持续记录进度。
- 自然语言行动可直输：玩家可直接输入行动描述，不依赖固定选项操作。
- 故事滤镜已接入主流程：不合理动作会结合地点、背包、主线与角色状态，被重解释为当前故事内成立的行为。
- 偏航动作可被吸收：偏离主线的行动不会伪造“假支线”，而是转化为贴近现场的即时叙述。
- NPC 可参与回合制推进：NPC 拥有先攻顺序、行动点、位置、公开状态与私有状态，会在自己的回合中行动。
- NPC 支持 LLM 驱动决策：服务端会为 NPC 构建受限的可见信息 `ActorObservation`，LLM 只基于这些信息产出行动意图；未配置模型或调用失败时，会自动回落到规则决策。
- 玩家与 NPC 信息边界已隔离：玩家快照不会暴露 NPC 的隐藏动机和私有记忆，NPC 决策也不会直接读取完整服务器真相。
- 场景已向物件级细化：地点内可包含家具、容器、设备、人物与危险源，线索和关键物资会挂在具体物件上。
- 回合节奏已进一步规则化：每次有效互动消耗 1 点行动点，先攻顺序按每回合掷骰排序，角色会按顺序轮流推进。
- 本地存档完整可用：支持保存、恢复与继续旧局。

## 项目结构

- `client/`：Vite + React 前端
- `server/`：Express 服务端、规则引擎、AI 服务接入
- `shared/`：共享类型、模板和常量

## 环境准备

安装依赖：

```bash
npm install
```

如果要使用自定义故事生成，请在项目根目录准备 `.env`，至少配置：

```bash
LLM_API_KEY=your_key
LLM_MODEL=your_model
LLM_BASE_URL=https://api.moonshot.cn/v1
```

未配置模型时，默认模板玩法仍可运行，但自定义故事生成会直接报错。

自定义故事当前可通过一次生成获得可开玩的初始内容（剧本与角色），并在后续游玩中结合规则引擎持续推进体验。

## 当前实现边界（现状）

- 当前定位仍是单人原型，尚未扩展为完整的多人群像系统。
- 自定义故事已支持动态地点、动态角色、秘密目标、NPC 回合与故事滤镜，但底层仍由部分规则引擎提供稳定性兜底。
- NPC 已具备“按可见信息行动”的架构基础，但还不是完整的通用多智能体沙盒；目前 LLM 决策会被归一到有限动作类型，再由规则引擎裁决结果。
- 复杂场景和物件交互已经进入规则层，但仍处于“新物件结构逐步替换旧硬编码目标”的过渡阶段。
- 故事滤镜当前以“动作重解释”为核心能力，尚未演进为完全自由生成的长期剧情代理。
