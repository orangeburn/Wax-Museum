# 蜡像馆

《蜡像馆》当前是一个以中文互动悬疑为核心的单人叙事游戏原型。项目包含 React 客户端、Express 服务端和共享类型包，支持本地存档、自定义故事生成、自然语言行动输入，以及基于故事上下文的“故事滤镜”。

## 当前能力

- 默认模板玩法：可以直接进入固定模板局进行游玩。
- 自定义故事生成：输入一句 Prompt，系统会生成故事背景、角色、地点和主线节点。
- 动态角色：自定义故事中的角色不再固定为工程师/医生/保安/路人，而是由故事题材生成。
- 秘密目标：每个可选角色会生成可见的私密任务，并在游玩过程中追踪进度。
- 自然语言交互：玩家可以直接输入自然语言，而不必只点固定选项。
- 故事滤镜：不合理动作会根据当前地点、背包、主线和角色状态被重新解释为当前故事里成立的行为。
- 动态偏航吸收：偏离主线的动作不会伪造“假支线”，而会被吸收成贴近现场的即时叙述。
- 本地存档：支持保存、恢复和继续旧局。

## 项目结构

- `client/`：Vite + React 前端
- `server/`：Express 服务端、规则引擎、AI 服务接入
- `shared/`：共享类型、模板和常量

## 环境准备

安装依赖：

```bash
npm install
```

如果要使用自定义故事生成，请在项目根目录准备 `.env`，至少配置：

```bash
LLM_API_KEY=your_key
LLM_MODEL=your_model
LLM_BASE_URL=https://api.moonshot.cn/v1
```

未配置模型时，默认模板玩法仍可运行，但自定义故事生成会直接报错。

## 本地运行

```bash
npm run dev
```

默认开发地址：

- 客户端：`http://127.0.0.1:5173/`
- 服务端：`http://127.0.0.1:8787/`

## 测试

运行整套测试：

```bash
npm test
```

如果只想跑某一侧：

```bash
npm run test --workspace server
npm run test --workspace client
```

## 构建

```bash
npm run build
```

## 当前实现边界

- 目前仍然是单人原型，不是完整的多人群像系统。
- 自定义故事已经支持动态地点、动态角色、秘密目标和故事滤镜，但底层仍有一部分规则引擎负责兜底。
- 故事滤镜当前以“动作重解释”为主，还不是完全自由生成的长期剧情代理。
